# BLISS — разбор сценария и решения

Рабочее задание: [`PROMPT.md`](PROMPT.md). Здесь — короткий разбор и выбранные решения.
Любое решение ниже обратимо; если меняем — правим этот файл.

## 1. Сценарий

**Клиент** (без входа, с телефона):
1. Открывает ссылку → видит 3D-мебель, которую можно вращать.
2. Выбирает категорию (диван, кресло, матрас, стул, «Другое») и вариант, количество, «сильные загрязнения», для матраса — «вторая сторона».
3. Добавляет в корзину, может собрать несколько предметов, поменять, удалить (с отменой).
4. Оформление: имя, телефон, адрес, «за город», желаемые дата/время, до 3 фото, комментарий, согласие.
5. После записи в базу получает **приватную ссылку** `/z/<токен>` — состав, статус, цена, время. Владелец меняет — клиент видит там же.
6. (Необязательно) мини-игра «почисти пятна».

**Владелец** (кабинет `/admin`, пароль):
- Заявки: поиск, фильтры, состав, фото, расчёт, история; ставит итоговую цену и время, меняет статус, пишет приватную заметку.
- Тарифы, Компания, Игра, Персонажи, Доступ.

Статусы: `новая` → `согласована` (нужны цена и время) → `завершена`; из любой — `отменена`.

## 2. Правила расчёта (одна формула)

Все суммы — целые числа в основной валюте (без копеек).

Для каждой позиции с известной ценой:

```
база        = цена варианта × количество
надбавки    = сильные загрязнения % + вторая сторона матраса %   (складываются, НЕ перемножаются)
позиция     = округлить_до_10( база × (1 + надбавки / 100) )
```

Для заказа:

```
чистка_известная = сумма позиций с известной ценой
чистка           = max(чистка_известная, минимальный заказ)   — только если есть хотя бы одна позиция с ценой
выезд            = фиксированная доплата, если «за город»
итог_предварит.  = чистка + выезд
```

- Округление: до 10 в большую сторону от половины (5 → вверх), **по каждой позиции**, чтобы строка в корзине совпадала с итогом.
- Минимум относится только к чистке. Выезд добавляется после минимума.
- «Другое» → цена «По фото», в сумму не входит, бесплатной не показывается. В смешанном заказе показываем: «Известно: X + N предмет(ов) по фото».
- Если в заказе только «Другое» — итог «По фото», минимум не применяется (владелец оценит сам). Выезд показывается отдельной строкой.
- Сервер пересчитывает заявку по текущему прайсу и **сохраняет снимок прайса** в заявке. Сумма из браузера не принимается.
- Размеры (2/3 места, угловой и т.п.) пока меняют только тариф; 3D-модель одна на категорию, и интерфейс не делает вид, что модель перестроилась.

Цены по умолчанию — демо, меняются в «Тарифах». Валюта задаётся в «Компании».

## 3. Хранение данных

- **PostgreSQL** (в проде — Neon или Supabase, бесплатный тариф). ORM — Drizzle.
- Для разработки и тестов — **PGlite** (Postgres в процессе), без внешних аккаунтов.
- Фото: сжимаются на сервере (sharp, до ~1600 px, WebP), хранятся в базе (`bytea`), отдаются только через проверяющий маршрут: клиенту — по токену его заявки, владельцу — по сессии. Предсказуемых адресов нет.
- Заявка хранит: состав, снимок прайса, предварительный расчёт, пожелания, статус, итоговую цену/время, историю изменений, приватную заметку владельца (наружу не отдаётся).
- Повтор отправки: клиент шлёт `idempotency key`; второй запрос с тем же ключом возвращает ту же заявку.
- Корзина и черновик формы — в `localStorage` браузера.

## 4. Безопасность (MVP)

- Пароль владельца — scrypt-хэш; сессия — случайный токен в httpOnly cookie, хранится хэш. Смена пароля закрывает все сессии.
- Проверка входных данных (zod) на сервере, проверка `Origin` для изменяющих запросов, ограничение частоты заявок и входа.
- Токен заявки — 32 случайных байта (base64url). Номер заявки отдельно и наружу ничего не открывает.

## 5. 3D

- Three.js + React Three Fiber + Drei. Одна сцена, мягкая смена предмета, OrbitControls с ограничениями, кнопка «сброс ракурса», тень в сцене.
- Модели: бесплатные с лицензией, разрешающей коммерческое использование и передачу (CC0 в приоритете). Источники и лицензии — в `docs/ASSETS.md`.
- Без WebGL — постер, заказ остаётся доступен. Учитываем `prefers-reduced-motion`, ограничиваем DPR.
- Лица/руки/моргание — после подключения Blender MCP.

## 6. Стек

Next.js (App Router) + React + TypeScript, Motion для UI, Drizzle + PostgreSQL, Vitest для тестов формулы и API.
