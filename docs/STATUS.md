# Состояние проекта

Обновлено: 18 ноября 2026.

## Что есть

Ветки `main` (3D-персонажи, 3D-конфигуратор, корзина) и `claude/busy-cerf-rs4lid` (оформление заявки, база, приватная ссылка, кабинет) объединены:

- главная: 3D-конфигуратор и корзина из `main`; кнопка «Оформить заявку» ведёт на `/oformlenie`;
- оформление, приём заявки, приватная ссылка `/z/<токен>` и кабинет `/admin` работают с корзиной из `main` (`src/lib/cart/store.ts`);
- прайс и название компании для главной берутся из базы (кабинет → «Тарифы», «Компания»);
- общая шапка (`SiteHeader`, ссылка «Заказ · N» ведёт к корзине на главной) и подвал для всех публичных страниц.

Из ветки `claude/busy-cerf-rs4lid` при слиянии убраны дубли: свой конфигуратор, своя корзина и страница `/korzina`, SVG-иллюстрации мебели (их заменили постеры из Blender).

Проверено на PGlite и на настоящем PostgreSQL 16 (серверные тесты, одновременный холодный старт нескольких экземпляров, вся цепочка в браузере): 66 тестов, типы, линтер, сборка; в браузере — полная цепочка (выбор в 3D → корзина → оформление с фото → повтор после обрыва без дубля → кабинет: согласование цены и времени → клиент видит обновление), смена тарифа в кабинете попадает в 3D-конфигуратор, телефон и широкий экран, тёмная тема, запасной постер без WebGL. На реальном телефоне — не проверено.

## Опубликованный сайт

Проект `myagko-clone` на Vercel собирается из `main`. Чтобы на нём заработали заявки и кабинет, после слияния PR нужно в Vercel → проект → Settings:

1. Storage → подключить PostgreSQL (например, Neon) — Vercel сам добавит `DATABASE_URL`;
2. Environment Variables → `ADMIN_PASSWORD` (не короче 8 символов);
3. Redeploy.

Без `DATABASE_URL` публикация соберётся и витрина (3D, выбор, корзина) будет работать на демо-ценах, но отправка заявки и кабинет на хостинге работать не будут: хранить заявки в файле на serverless нельзя.
