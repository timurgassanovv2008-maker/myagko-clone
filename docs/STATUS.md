## Где что лежит

| Ветка | Что в ней | Статус |
|---|---|---|
| `main` | Основа, формула цены, 3D-персонажи (Blender, GLB, постеры, `docs/ASSETS.md`), 3D-конфигуратор, корзина (PR #1–#3 из ветки `claude/determined-brown-2q1mvn`) | Опубликовано на Vercel (проект `myagko-clone`, адрес — в Vercel → Projects → myagko-clone → Domains) |

## Главная задача следующей сессии — объединить ветки

1. Подтянуть свежий `main`.
2. Взять из `main` 3D-конфигуратор, модели и корзину.
3. Перенести из `claude/busy-cerf-rs4lid`: оформление (`src/app/(site)/oformlenie`), приватную ссылку (`src/app/(site)/z`), API (`src/app/api`), сервер (`src/server`), кабинет (`src/app/admin`, `src/proxy.ts`), схему и миграции (`drizzle/`), `src/lib/order.ts`, `src/lib/tz.ts`, `src/lib/format.ts`, тесты.
4. Свою корзину и конфигуратор из `claude/busy-cerf-rs4lid` не переносить — подключить оформление к корзине из `main` (её хранилище `src/lib/cart/store.ts`).
5. Проверить: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, всю цепочку в браузере (клиент отправил → владелец согласовал → клиент увидел), телефон и тёмную тему.
6. Открыть PR в `main`.

## После объединения

- Подключить к проекту на Vercel базу PostgreSQL (Neon через Vercel Marketplace) и задать `ADMIN_PASSWORD` в настройках проекта (Environment Variables).
- Дальше по `docs/PLAN.md`: игра с пятнами, разделы кабинета «Игра» и «Персонажи», PWA, sitemap/robots, макеты в Figma, проверка на реальном телефоне.

## Уроки

- Работать в одной сессии за раз; новую сессию начинать после слияния PR, со свежего `main`.
- В начале сессии всегда смотреть `main` и открытые/влитые PR.
